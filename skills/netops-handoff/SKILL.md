# Incident handoff draft

Work directly from supplied case records, run reports, or operator notes. Preserve the affected operation and scope, observations versus hypotheses, evidence references and counterevidence, action outcome, verification gaps, current status, owner, and next action. Mark missing information and uncertainty rather than inventing a cause, an owner, or recovery. Redact sensitive details as appropriate for the intended audience and retain restricted originals separately.

Produce a local draft only. Do not send a message, write a ticket, or change a device as part of drafting. See [handoff details](references/handoff.md) for a compact structure and provenance checks.
