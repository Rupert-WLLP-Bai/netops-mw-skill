## Agent skills

Use English for project documentation, code, comments, test descriptions, and generated reports. Use concrete terms such as "test inputs" and "sample tool output."

### Issue tracker

Tasks and specifications live in the GitHub Issues of Rupert-WLLP-Bai/netops-mw-skill. Read `docs/agents/issue-tracker.md` before working with tickets.

### Triage labels

Use the five default triage state labels. Read `docs/agents/triage-labels.md` before classifying tickets or changing their state.

### Domain docs

Use a single domain context: root `GLOSSARY.md` and `docs/adr/`. Read `docs/agents/domain.md` before exploring domain concepts, designing interfaces, or recording decisions.
