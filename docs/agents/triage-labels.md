# Triage Labels

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Additional information needed |
| ready-for-agent | ready-for-agent | Sufficiently specified for agent implementation |
| ready-for-human | ready-for-human | Human implementation or judgment needed |
| wontfix | wontfix | Will not be implemented |

Use this mapping when an engineering skill refers to a triage role. Edit the repository-label column if the team's vocabulary changes.
